---
name: followup-earlier-work
title: Follow-up on earlier work
triggers: continue, as before, like last time, the file we made, update the report you wrote, same as yesterday, redo
examples:
  - "continue where we left off"
  - "update the summary you made yesterday with the new file"
  - "do the same for the other folder"
applies_when: the request builds on something from this or an earlier conversation
---
**Done looks like:** the earlier result found and reused (not rebuilt), the change applied, and a note of what changed.
**Approach:** check the open checklist and recent files first; memory_search / search_documents for the earlier deliverable; open it; apply the delta; keep the previous version unless told to overwrite.
**Tools:** memory_search; search_documents; list_dir; read_file / read_document; edit_file; artifact_edit.
**Pitfalls:** redoing the whole task; editing the wrong (older) copy; forgetting constraints agreed earlier (check notes/memories).
**Verify:** the new output differs from the old only in the requested way.
**Stop / ask:** if the earlier artifact cannot be found, say so and offer to rebuild from the inputs.
