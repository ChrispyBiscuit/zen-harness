---
name: draft-message
title: Draft an email, message or post
triggers: write an email, draft a message, reply to, announcement, post for, letter to, respond to this
examples:
  - "draft a polite follow-up email to a supplier about a late delivery"
  - "write an announcement for the team about the new schedule"
  - "reply to this customer complaint"
applies_when: the user wants text they will send or publish
---
**Done looks like:** the ready-to-send text in the chat (and a file only if asked), in the right tone and length, with placeholders marked where facts are missing.
**Approach:** follow read_guide('clear_writing'); identify audience, goal and the one thing the reader must do; draft; cut it by a third; mark anything uncertain in [brackets].
**Tools:** usually none; read_file / read_document for context; memory_search if the user has stated preferences before.
**Pitfalls:** inventing names, dates or commitments; generic filler; sending or posting anything yourself (never — the user sends it).
**Verify:** every factual element came from the user or their files.
**Stop / ask:** tone or key facts if missing; otherwise draft with placeholders and offer a variant.
